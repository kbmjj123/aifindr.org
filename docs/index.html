Get Started

Quick Start

Run aifindr.org locally in under 5 minutes.

1
Clone the repository

Fork or clone the repo to your local machine.

git clone https://github.com/kbmjj123/aifindr.org.git cd aifindr.org
2
Install dependencies

Requires a recent Node.js LTS with pnpm 10 enabled.

pnpm install
3
Configure environment

Public values live in wrangler.toml; put local secrets in .dev.vars (git-ignored). See the Environment Variables section below.

cp .env.example .env # .dev.vars holds local secrets; wrangler.toml supplies D1/KV/R2 bindings
4
Start the dev server

Nuxt + Nitro run together; the /api/* endpoints are served by the same process at localhost:3000.

pnpm dev # → http://localhost:3000
5
Deploy to Cloudflare Workers

A single Worker serves both pages and APIs (main + assets declared in wrangler.toml).

pnpm build wrangler deploy
Architecture

Project Structure

Key directories and what they contain.

aifindr.org/
  pages/  ── Nuxt route pages (tools, blog, admin, submit...)
  components/  ── Vue UI components
  composables/  ── shared logic (useApi, useAuth, usePageSeo...)
  server/routes/api/  ── ~45 Nitro API endpoints
  server/utils/  ── env, auth, jwt, email, cron helpers
  schema/  ── D1 SQL (init.sql, reset.sql) — 9 tables
  types/  ── tool / category type definitions
  assets/css/  ── CSS variables + Tailwind v4 theme
  docs/  ── this GitHub Pages site + design notes
  nuxt.config.ts  ── Nuxt / Nitro / SEO configuration
  wrangler.toml  ── Worker entry, assets, D1/KV/R2 bindings, crons
  CLAUDE.md  ── project guide (CODEBUDDY.md is a symlink)
  .env.example  ── R2 variables for the image migration script
Configuration

Environment Variables

Public values live in wrangler.toml under [vars]; secrets are set with wrangler secret put (locally in .dev.vars). See CloudflareEnv in server/utils/env.ts.

Variable Description Where
API_BASE / R2_PUBLIC_URL Public site URL and CDN base [vars]
GITHUB_CLIENT_ID GitHub OAuth app client ID [vars]
ADMIN_GITHUB_IDS Comma-separated admin GitHub IDs [vars]
JWT_SECRET / TURNSTILE_SECRET JWT signing and form anti-spam Secret
RESEND_API_KEY Transactional email delivery Secret
DB / CACHE / CDN D1 database, KV cache, R2 bucket bindings Binding
Contributing

How to Contribute

Two ways to contribute — submit tools or improve the codebase.

🛠 Submit a Tool

Submit via the online form. The tool enters a review queue in the admin dashboard and, once approved, earns 3 free dofollow backlinks. Tool data lives in Cloudflare D1, not in Markdown files.

Submission Guide →
💻 Improve the Code

Bug fixes, new features, UI improvements — all welcome. Open an Issue first to discuss larger changes before submitting a PR.

Open an Issue →
⭐ Star the Repo

The simplest contribution. Starring the repo helps more people discover the project and signals to search engines that the project is active.
