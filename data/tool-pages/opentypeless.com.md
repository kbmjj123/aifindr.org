## Verification status

**UNVERIFIED.** This is a category mismatch as much as a test limit: the product is described as a desktop application, while our harness only drives a browser. Microphone capture and OS-level text insertion are outside what this run can observe. We therefore make no claim about transcription accuracy or context-aware rewriting.

## FAQ

**Did you test voice dictation?**
No. There was no in-browser dictation control on the homepage, and our harness does not install or run desktop software.

**Is it open source?**
That is the site's claim, backed by a docs link on the page. We did not inspect a repository.

**What would a fair test require?**
Installing the desktop app and capturing microphone input locally — a different procedure from the browser-based checks used for this batch.
