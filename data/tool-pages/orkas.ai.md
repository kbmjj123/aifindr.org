## What the site says

> The following is the site's own description. It has not been verified by us.

Orkas describes a tool for solo founders and small teams to direct AI agents by chat, producing research, documents, slides, videos, websites and more. It says the product is free, open source, and available for Mac and Windows.

## What we checked

- 2,585 visible words and 66 links; pricing and docs links are present alongside terms and privacy, but no login or signup link was detected in the crawled links.
- No analytics ID and no external model-provider domain appeared in the static HTML.
- `robots.txt` is present without a blanket disallow, and the terms page contained no detected ban on automated access.
- The tested URL carried `?source=dir_aifindr`, a directory-referral parameter.

## Hands-on run

We found 0 file inputs, 0 text inputs, 1 textarea and 38 buttons, with 0 visible input fields. The single contenteditable element was not visible, so no chat message could be entered. The run ended at inspection; no backend call, no output and only the landing screenshot were saved.

## Verification status

**UNVERIFIED.** Despite a chat-first product description, the public page did not expose a usable chat input to an anonymous visitor. Because the site also describes desktop apps for Mac and Windows, the working interface may live outside the browser. We did not install anything, so nothing about agent orchestration or output quality is confirmed.
