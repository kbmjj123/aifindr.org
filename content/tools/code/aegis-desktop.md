## Follow your agent beyond the chat window

AEGIS brings detected agent processes, process trees, configured file activity
and TCP endpoint observations into one desktop workspace. Developers can review
alerts, inspect local security configuration and export investigation records.
Claude Code usage subtotals and estimated costs add local usage context.

The application is MIT-licensed, with a published Windows beta. Monitoring
requires no agent plugin or subscription. Process actions are explicit;
selected-action policies and MCP gateways need separate setup. macOS and Linux
support remain experimental.

[Explore AEGIS and download the Windows beta](https://antropos17.github.io/aegis-media/)
