Submitted on behalf of the Jev Agent team.

Jev Agent offers browser tools, REST APIs and a hosted MCP server for structured text evaluations. Its seven MCP tools cover yes/no judgments, choices, rubric scores, version comparisons, resume matching, essay grading and grading with a custom rubric.

The hosted MCP endpoint is https://jev-agent.com/api/mcp and uses Streamable HTTP. Connection documentation is available at https://jev-agent.com/jev-mcp. Evaluations require an API key and usage credits; limited trials are available. Human review remains appropriate for consequential education or hiring decisions.

Jev Agent is an independent service and is not the official TypeSafe AI Jev platform. Contact: support@jev-agent.com.
