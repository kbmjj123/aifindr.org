FrameThrower helps filmmakers and advertising creatives find film stills, movie screenshots, and cinematography references for inspiration and learning. Search by visual concepts, explore lighting and composition, organise references into lookbooks, and export PDF boards or ZIP files.

Developer integrations include a REST API, MCP server, npm SDK, and ComfyUI node. The web app is freemium, with paid Pro plans; API usage is billed separately. [Developer documentation](https://framethrower.ai/developers).
